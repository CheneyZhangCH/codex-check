# 习惯打卡

一个纯前端、无需服务器的习惯打卡网页:每天打开,完成一项点一下打勾,支持今日进度、月度视图和年度视图。

## 使用方法

直接用浏览器打开 `index.html` 即可使用,无需安装任何依赖。

- **今天**:查看今日进度(已完成 n/总数),点击右侧圆圈打勾;点击习惯名称可编辑或删除。
- **月视图**:查看当月每天完成情况,点击任意一天可以补打卡。
- **年视图**:12 个月一览 + 年度统计,点击月份卡片可跳转到该月。

首次打开会自动内置「喝水、活动肩膀、读书」三个示例习惯,不需要可以直接删除。

## 数据保存

- 数据保存在本机浏览器的 localStorage 中,关闭页面不会丢失。
- 换浏览器或换设备时,用页脚的「导出数据」下载 JSON 备份,再到新设备点「导入数据」恢复。
- 清空浏览器站点数据会删除打卡记录,建议定期导出备份。

## 文件说明

- `index.html` — 页面结构
- `styles.css` — 样式(含移动端适配和深色模式)
- `app.js` — 全部交互逻辑
